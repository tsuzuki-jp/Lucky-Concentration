# 運ゲー神経衰弱

場のカードをめくるか、山札から引いてくるか。記憶力より運がものを言う神経衰弱です。
`index.html` 1ファイルだけで動くブラウザゲーム（ライブラリ・ビルド不要）。

## ルール

1. トランプ52枚を使用。最初は場に4枚（2×2）が伏せてあり、残り48枚は山札。
2. 自分の番に2枚めくる。1枚ごとに次のどちらかを選ぶ。
   - 場に伏せてあるカードをめくる
   - 山札の一番上をめくって場に出す（2枚とも山札からでもOK）
3. 2枚が同じ数字ならペア獲得。場から取り除いて、もう1回。
4. ちがう数字なら2枚とも場に伏せて交代。山札から出したカードはそのまま場に残る。
5. すべてのカードがなくなったら終了。ペアの多い人の勝ち。

### このゲーム独自の仕様

- 1〜4人で遊べる（1台を回して遊ぶ方式）。1人のときはターン数を競い、自己ベストをブラウザに保存。
- 2枚目が「まだ誰も見ていないカード」で揃ったときは「運ゲー成功」としてカウント。
- 場は 2×2 → 3×3 → 4×4 … と外側に広がるので、既存のカードの位置は動かない。
  ペアが取られて空いたマスには、次に山札から出たカードが入る。

## 遊び方

`index.html` をブラウザで開くだけ。

## GitHub Pages で公開する

1. GitHub の Settings → Pages → Build and deployment → Source で「Deploy from a branch」、`main` ブランチ / `/ (root)` を選んで Save
2. 数分後に https://tsuzuki-jp.github.io/Lucky-Concentration/ で遊べる

## 調整したいとき

`index.html` 内の定数を変えるだけで挙動を変えられる。

| 定数 | 内容 |
| --- | --- |
| `INITIAL_FIELD` | 最初に場に伏せる枚数（既定 4） |
| `DELAY.match` / `DELAY.miss` | 揃ったとき／外れたときの表示時間（ミリ秒） |
| `RANKS` / `SUITS` | 使うカードの構成 |
